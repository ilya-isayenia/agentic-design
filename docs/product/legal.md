# Legal placeholders

The demo has no real terms. The consent checkbox links to these placeholders; each opens a page that says it is a placeholder.

| Link text | Placeholder |
| --- | --- |
| Membership terms | `#/legal/terms` |
| Privacy notice | `#/legal/privacy` |
| Club rules | `#/legal/rules` |
| Direct debit mandate | part of the consent sentence: "and authorise monthly direct debit from this account" |

Payment, SMS and maps are stubs: nothing is charged, sent or located.
