# Components

Every component lives in `packages/ui/src/components/<Name>/` with its contract (`<Name>.contract.md`: purpose, API, states, tokens, accessibility, do and don't), stories (one per state plus a Matrix story over all six themes) and tests. Import from `@agentic/ui`.

| Component | Purpose | States (stories) |
| --- | --- | --- |
| [Banner](../../packages/ui/src/components/Banner/Banner.contract.md) | A promo strip across the top of the page with a countdown to the end of an offer. One per page. It is not for errors or system messages; use Toast or ErrorState. | Running, LastHour, Ended, WithoutAction, NonDismissible, Keyboard, Matrix |
| [Button](../../packages/ui/src/components/Button/Button.contract.md) | Starts an action: submit a step, join, retry, apply. One primary button per view region; the rest are secondary or ghost. | Primary, Secondary, Ghost, WithIcon, Small, Large, Disabled, Loading, Matrix |
| [Checkbox](../../packages/ui/src/components/Checkbox/Checkbox.contract.md) | A single yes/no: consent, terms, newsletter. The label is the slot and may contain links. | Unchecked, Checked, Required, WithLink, Invalid, Disabled, Keyboard, Matrix |
| [Chip](../../packages/ui/src/components/Chip/Chip.contract.md) | A small rounded tag. As a `span` it lists a perk of a club or plan ("Sauna", "24/7 access"). As a `button` it is an on/off filter in the club finder. | Neutral, Accent, WithIcon, Toggle, TogglePressed, Matrix |
| [ClubCard](../../packages/ui/src/components/ClubCard/ClubCard.contract.md) | One club in the club finder list: a placeholder photo, name, address, perks, the lowest price per 4 weeks, and two actions: read more or start the signup at this club. | Default, Promo, PromoTicker, Selected, LongText, NoPerks, HeadingLevel, Matrix |
| [EmptyState](../../packages/ui/src/components/EmptyState/EmptyState.contract.md) | Fills a region that loaded fine but has nothing to show: no search results, no bookings yet. It says why it is empty and, where possible, offers the next step. For a failure use ErrorState; for loading use Skeleton. | Default, WithAction, TitleOnly, SubsectionHeading, Matrix |
| [ErrorState](../../packages/ui/src/components/ErrorState/ErrorState.contract.md) | Replaces a region whose content failed to load or save, says what went wrong and offers a retry. For a region that loaded but is empty use EmptyState; for a field error use the field's own message. | Default, Retrying, Silent, TitleOnly, Keyboard, Matrix |
| [IconButton](../../packages/ui/src/components/IconButton/IconButton.contract.md) | An action shown only as an icon: close, dismiss, previous/next, favourite toggle. Use it only where the icon is widely understood; otherwise use Button with text. | Ghost, Primary, Secondary, Small, Keyboard, Pressed, Disabled, Matrix |
| [PlanCard](../../packages/ui/src/components/PlanCard/PlanCard.contract.md) | A selectable card for a plan or membership type: title, perks, optional price and promo ribbon. Behaves as one radio inside a RadioGroup. | Default, Selected, Promo, Disabled, NoPrice, LongText, Keyboard, Matrix |
| [Price](../../packages/ui/src/components/Price/Price.contract.md) | Shows a price in euros, optionally with the price before a promo, a lead ("From") and a period ("/4 weeks"). Used in PlanCard, ClubCard and Receipt. | Regular, Promo, Cents, Small, Large, Matrix |
| [Radio](../../packages/ui/src/components/Radio/Radio.contract.md) | One option inside a RadioGroup. A native `<input type="radio">` nested in its label; the whole 48 px row is the target. | Default, Checked, Disabled, SlotLabel, Matrix |
| [RadioGroup](../../packages/ui/src/components/RadioGroup/RadioGroup.contract.md) | One choice from a few options shown at once. Owns the value, the shared `name`, required and error; gives them to Radio and PlanCard children through `radioGroupKey` (`radioGroup.ts`). | NoneSelected, Selected, WithHint, Required, Invalid, Disabled, HiddenLegend, Keyboard, Matrix |
| [Receipt](../../packages/ui/src/components/Receipt/Receipt.contract.md) | The order summary beside the signup steps: which club, what each part costs, and the total every 4 weeks. It only lays out what the app passes in; prices come from the app's pricing data. Sticky positioning is the app's job. | Empty, ClubOnly, Filled, WithFooter, Matrix |
| [ReceiptLine](../../packages/ui/src/components/ReceiptLine/ReceiptLine.contract.md) | One line of the membership receipt: a label on the left, a price on the right, an optional note under the price and optional details behind a disclosure. The `total` emphasis is the last line of the receipt. | Regular, Promo, WithNote, Total, WithDetails, Expanded, Matrix |
| [Select](../../packages/ui/src/components/Select/Select.contract.md) | Choose one value from a known short list (home club, country, title). Native `<select>`, styled like TextField, so mobile pickers and keyboard behaviour come from the platform. | Empty, Selected, WithHint, Required, Invalid, Disabled, Keyboard, Matrix |
| [Skeleton](../../packages/ui/src/components/Skeleton/Skeleton.contract.md) | A placeholder in the shape of content that is still loading (plan cards, club list, receipt). Use it when the layout is known; use a Spinner inside a Button for a submit in progress. | Text, SingleLine, Rect, Circle, Labelled, Matrix |
| [StepIndicator](../../packages/ui/src/components/StepIndicator/StepIndicator.contract.md) | Shows where the user is in the 5-step signup and lets them go back to any finished step. It does not switch steps itself: it emits `go`, the app changes the step and moves focus to the new step's heading. | First, Middle, Keyboard, WentBack, Last, Matrix |
| [Stepper](../../packages/ui/src/components/Stepper/Stepper.contract.md) | Pick a small whole number with − and + buttons, e.g. workouts per week or guest passes. | Default, AtMin, AtMax, PlainNumber, Keyboard, Matrix |
| [TextField](../../packages/ui/src/components/TextField/TextField.contract.md) | One line of text input with a visible label: names, email, phone, address, IBAN. The base for every text entry in the signup form. | Empty, Filled, WithHint, Required, Invalid, Disabled, Readonly, WithEndSlot, Keyboard, Matrix |
| [Toast](../../packages/ui/src/components/Toast/Toast.contract.md) | A short message after an action that does not need an answer: saved, copied, sent, failed. It closes itself. Anything the user must act on goes in the page (ErrorState, a field error), not in a toast. | Info, Success, Danger, ClosesItself, PausesOnHover, Keyboard, Matrix |

Internal parts: `Icon` (stroke icons, `icons.ts`), `Spinner`, `FieldError` (shared error line of form fields).

Charts are not built yet: they are hand-written SVG components on the `chart-*` tokens, without a chart library, made through `/change`.
